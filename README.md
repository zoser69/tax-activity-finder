# دليل أكواد الأنشطة الضريبية (PWA)

تطبيق ويب تقدمي (Progressive Web App) خفيف وسريع للبحث الفوري في دليل أكواد الأنشطة الضريبية المصرية (435 نشاطاً).

## المميزات
- بحث ذكي بالاسم الرسمي أو الاسم الدارج أو الكود الضريبي مع دعم المترادفات والأخطاء الإملائية البسيطة.
- تصفية حسب التصنيف (مطاعم وكافيهات، تجارة وتجزئة، مقاولات وعقارات، إلخ).
- نسخ الكود بضغطة واحدة.
- يدعم التثبيت على الموبايل (Android / iOS) والعمل بالكامل بدون إنترنت (Offline).
